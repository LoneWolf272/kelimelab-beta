KelimeLab Beta — Kurulum

Dosyaları yalnızca kelimelab-beta deposunun köküne yükleyin. Settings > Pages > Deploy from a branch > main / (root) > Save. Yeni Pages adresini Safari ile açıp Ana Ekrana Ekle seçeneğini kullanın. Beta sıfır ilerlemeyle başlar. Ana uygulamanın deposuna yüklemeyin. Kişisel yedekleri herkese açık depoya yüklemeyin.
